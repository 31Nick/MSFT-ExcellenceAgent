# ExcellenceAgent

**Azure APRL v2 Report Analyser & ADO Work-Item Generator**

ExcellenceAgent ingests [Azure Proactive Resiliency Library (APRL) v2](https://azure.github.io/Azure-Proactive-Resiliency-Library-v2/) Excel reports, intelligently groups recommendations into actionable work packages using a configurable resource matrix, and exports Azure DevOps-compatible CSV files for bulk work-item creation.

## Features

- **Excel Ingest** — Parse APRL v2 reports with full column validation
- **Smart Grouping** — Map resources to domain categories using a configurable matrix (Observability, Platform, Compute, Data, Networking, Apps, AI)
- **4-Level ADO Hierarchy** — Generates Epics → Features → User Stories → Tasks with comprehensive descriptions and acceptance criteria
- **Deduplication** — Identical recommendations across multiple resources collapse into single User Stories with child Tasks
- **Pattern Detection** — Identifies cross-domain patterns, high-impact clusters, and resource-group hotspots
- **ADO CSV Export** — UTF-8 BOM CSV with indented title columns for direct ADO bulk import
- **Web Dashboard** — Flask-based UI for visual hierarchy exploration, pattern insights, and export configuration
- **LLM Enrichment** (Optional) — Azure OpenAI integration for enhanced acceptance criteria, remediation steps, and semantic clustering

## Quick Start

### Prerequisites

- Python 3.11+
- An APRL v2 Excel report (generated by the Azure APRL tool)

### Installation

```bash
cd MSFT-ExcellenceAgent-v3
pip install -r requirements.txt
pip install -e .
```

### Configuration

Copy the example environment file and configure:

```bash
cp .env.example .env
```

Edit `.env` with your settings:

```env
# Required
APRL_REPORT_PATH=./input/report.xlsx

# ADO Export (optional — can also be set via CLI flags)
ADO_AREA_PATH=MyProject\MyTeam
ADO_ITERATION_PATH=MyProject\Sprint 1

# Optional — Azure OpenAI (for LLM enrichment)
AZURE_OPENAI_ENDPOINT=https://your-instance.openai.azure.com/
AZURE_OPENAI_API_KEY=your-key
AZURE_OPENAI_DEPLOYMENT=gpt-4o
```

## Usage

### CLI Commands

```bash
# Parse and show report summary
excellence-agent ingest --report path/to/report.xlsx

# Run full analysis pipeline
excellence-agent analyse --report path/to/report.xlsx

# Export ADO-compatible CSV
excellence-agent export --report path/to/report.xlsx --output ./output/ado_import.csv

# Export with ADO project settings
excellence-agent export --report path/to/report.xlsx \
  --output ./output/ado_import.csv \
  --area-path "MyProject\Infrastructure" \
  --iteration-path "MyProject\Sprint 1"

# Start web dashboard
excellence-agent serve --port 5000
```

Add `-v` for verbose logging on any command:

```bash
excellence-agent -v analyse --report path/to/report.xlsx
```

### Web Dashboard

```bash
excellence-agent serve
```

Open `http://localhost:5000` in your browser. Upload an APRL Excel report to:

1. **Dashboard** — View summary stats, impact breakdown, and epic overview
2. **Hierarchy** — Explore the interactive Epic → Feature → User Story → Task tree
3. **Patterns** — Review cross-domain pattern insights
4. **Export** — Configure Area/Iteration paths and download the ADO CSV

## ADO Work-Item Hierarchy

The APRL data maps to a 4-level Azure DevOps hierarchy:

```
Epic (Domain Category — e.g. "Networking")
 └── Feature (Resource Type — e.g. "Network Watchers")
      └── User Story (APRL Recommendation — e.g. "Deploy Network Watcher in all regions")
           └── Task (Individual Resource — e.g. "NetworkWatcher_northeurope")
```

### Importing into Azure DevOps

1. Run `excellence-agent export` to generate the CSV
2. In Azure DevOps, go to **Boards → Queries → Import Work Items**
3. Upload the CSV file
4. Map columns and confirm the import
5. Work items are created with full hierarchy, descriptions, acceptance criteria, and tags

## Resource Matrix Customisation

The `resource_matrix.yaml` file controls how Azure resource types map to Epic categories. Edit it to match your organisation's structure:

```yaml
categories:
  Observability:
    description: "Monitoring, logging, and diagnostics resources"
    resource_patterns:
      - "microsoft.operationalinsights/workspaces"
      - "microsoft.insights/components"
  
  Networking:
    description: "Virtual networks, gateways, and connectivity"
    resource_patterns:
      - "microsoft.network/virtualnetworks"
      - "microsoft.network/networksecuritygroups"
      # Add more patterns here

default_category: "Uncategorised"
```

**Matching rules:**
- Case-insensitive prefix matching against APRL resource types
- First match wins (order categories by specificity)
- Unmatched types go to `default_category`

## LLM Enrichment (Optional)

When Azure OpenAI is configured, the agent can enhance work items with:

- **Acceptance Criteria** — AI-generated specific, testable criteria based on APRL recommendation details
- **Remediation Steps** — Step-by-step instructions for each resource task
- **Semantic Clustering** — Discovers non-obvious groupings across recommendations

Enable by setting the Azure OpenAI environment variables in `.env`, then use the `--enrich` flag (or toggle in the web UI).
